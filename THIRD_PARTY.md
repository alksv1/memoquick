- Source: https://github.com/nlohmann/json/tree/v3.12.0
- Download: https://raw.githubusercontent.com/nlohmann/json/v3.12.0/single_include/nlohmann/json.hpp

This is a compile-time header, with no additional runtime service or library to install.

The Windows SDK's **C++/WinRT** headers by Microsoft are used for native geolocation.

- Source: https://github.com/microsoft/cppwinrt
- License: MIT; included in `third_party/LICENSE-cppwinrt.txt`.
- Headers are supplied by the installed Windows SDK at build time; no extra runtime is required.
